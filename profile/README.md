## ℹ️ About

UnitonApp is a home for **open-source developer tools, SDKs and payment integrations** around [The Open Network (TON)](https://ton.org) and the **Tegro Money** payment system. Ready-to-use connectors, API clients, documentation and example code to accept payments and build on TON — across PHP, Python, WooCommerce, WordPress and Django.
